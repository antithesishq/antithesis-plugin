# Cursor setup

* Add secrets:
  * `ANTITHESIS_API_KEY`
  * `ANTITHESIS_TENANT`

* Add the plugin: Plugins & MCPs → Add marketplace → Import marketplace, then enter `https://github.com/antithesishq/antithesis-plugin` and switch the `antithesis` plugin to "Default on".
* Install the latest version of [snouty](https://github.com/antithesishq/snouty#install-snouty) where the agent runs, such as in a cloud agent environment's install step. The plugin doesn't install it.

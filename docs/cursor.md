# Cursor setup

* Add secrets:
  * `ANTITHESIS_API_KEY`
  * `ANTITHESIS_TENANT`
  * `ANTITHESIS_REPOSITORY` (GAR repository url)
  * `ANTITHESIS_GAR_KEY`

* Add the plugin: Plugins & MCPs → Add marketplace → Import marketplace, then enter https://github.com/antithesishq/antithesis-plugin and switch the `antithesis` plugin to "Default on".
